# Golden Vector Specification

Golden vectors are generated from training or validation data only. They include
raw feature values, preprocessed feature values, Python predicted class,
probabilities, expected policy state, expected intervals, model version, and
feature-schema checksum.

Outputs:

- `embedded/golden_vectors/golden_vectors.json`
- `embedded/golden_vectors/golden_vectors.csv`
- `embedded/golden_vectors/golden_vectors.h`
