# Custom THERMAL-NEXUS Dataset

This directory holds the THERMAL-NEXUS native dataset. It is the primary
training corpus for the embedded ML pipeline. Everything here is **software-synthetic
software data**, generated by `simulator/temperature/`. It is **not** a hardware
measurement and **not** the ELM / Nepal carrier external sources.

## Layout

```text
Datasets/CustomDataset/
├── README.md
├── DATASET_CARD.md
├── raw/             # 96 raw per-run CSVs (12 scenarios × 8 seeds)
├── processed/       # combined model-ready dataset + manifests
└── splits/          # leakage-safe group splits: train / validation / test
```

## How to regenerate

```bash
# 1. Generate raw runs
.venv/bin/python -m simulator.temperature.generate \
    --config config/scenarios.yaml \
    --all --runs 8 \
    --output-dir Datasets/CustomDataset/raw

# 2. Build features + labels
.venv/bin/python -m ml.preprocessing.build_dataset \
    --input Datasets/CustomDataset/raw \
    --label-config config/labeling.yaml \
    --feature-config config/features.yaml

# 3. Split (run-group stratified)
.venv/bin/python -m ml.preprocessing.split_dataset \
    --input ml/data/processed/model_ready_dataset.csv \
    --output ml/data/splits

# 4. Copy the splits back to this directory
cp ml/data/splits/*.csv Datasets/CustomDataset/splits/
```

## Disclaimer
