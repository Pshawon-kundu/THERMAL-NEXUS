# KPI Definition Catalog

Implemented KPIs include sample count, inference count, transmission count,
packet delivery ratio, packet loss rate, retry count, latency statistics, alert
count, event-level warning lead time, missed-event rate, false-alert rate,
state-transition count, fault durations, and estimated software energy.

Every estimated energy KPI uses:

`value_type = ESTIMATED_SOFTWARE_VALUE`

Estimated energy is not measured Wh and is not STM32 hardware consumption.
