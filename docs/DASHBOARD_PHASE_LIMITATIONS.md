# Dashboard Phase Limitations

Current limitations:

- SQLite storage contains simulated software evidence only.
- The dashboard is local and offline; no cloud or authentication is implemented.
- Energy values are estimates, not hardware measurements.
- Radio metrics are simulated and make no XBee range claim.
- Embedded C export is hardware-independent and not STM32 firmware.
- C parity depends on an installed compiler.
- Physical TMP117 validation remains future work.
