# Dashboard Release Checklist

- Light theme configured in `.streamlit/config.toml`.
- Usage statistics disabled for local demo reproducibility.
- Team name displayed as `Thermal Nexus`.
- Dashboard uses the local SQLite database only.
- Dashboard states simulation limitations in the header.
- No cloud service or external dashboard dependency is required.
- Tables and charts load from imported evidence, not live hardware.
- Replay, KPI, model-readiness, and system-info tabs are present.
- Real hardware claims are absent unless supported by imported hardware evidence.
